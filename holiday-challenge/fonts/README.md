# Self-hosted fonts (coming-soon page)

Same files as `holiday-challenge/app/fonts/` on `preview/holiday-app` (Anton v27, Lato v25, latin subset,
from Google Fonts). Served from this folder so `/holiday-challenge/` makes no requests to Google
(no Google Fonts, no Google Analytics). Licensed under the SIL Open Font License 1.1: see `OFL-Anton.txt`
and `OFL-Lato.txt`. The `@font-face` rules are at the top of `../coming-soon.css`.
